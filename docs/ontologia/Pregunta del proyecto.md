# Pregunta del proyecto

Original: *¿qué representación sobrevive a las restricciones de información de un despliegue real y con
qué rapidez da una señal útil?* Ver [[H2 topologia bajo restriccion]].

La pregunta evolucionó: de "qué feature puntúa mejor en CICIDS" (respondida, irrelevante porque presupone
reconstrucción completa de paquetes) a si el **signo** de una feature fija transporta entre entornos
([[H3 signo segun mecanismo]]) y finalmente a validez de medición ([[Tesis vigente]]).

Reglas antes de proponer algo nuevo (de `PROJECT_NOTES.md`): ¿ya está planteada? ¿el instrumento puede medirlo?
¿qué control descarta la alternativa obvia? ¿qué resultado me haría abandonarla? Ver [[Cinco errores ya cometidos]].
