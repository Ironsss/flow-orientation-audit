# Host-pair bootstrap

Remuestreo por **cluster de host-pair** en lugar de por flujo (Field & Welsh 2007; Cameron 2008 para pocos clusters).
Efecto: intervalos de 0.014–0.018 → 0.27–0.41 en [[BoT-IoT]]. Pocos clusters (32 por grupo evaluable BoT-IoT,
25–40 en [[UNSW-NB15]]) → los intervalos percentil pueden subcubrir. Holm sobre 9/10 familias no cambió nada.
Parte de [[Auditorias A1-A4]].
