# Freeze → push → code → push → run una vez

Plan congelado y subido **antes** de escribir el código; código subido antes de ejecutar; se ejecuta una vez y
**el script calcula el veredicto**. Todo lo demás se etiqueta POST-HOC ([[Estado evidencial]]). Un dataset usado
como confirmatorio queda **gastado** para esa hipótesis. No es metodología nueva; se describe, no se reclama.
Cronología verificable con `git show`: `docs/methodology/PROVENANCE.md`.
