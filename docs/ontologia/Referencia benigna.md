# Referencia benigna

Población contra la que se calcula [[AUC_signed]]. Cada número debe nombrarla. Ejemplos: el Normal de [[BoT-IoT]]
(9,543 flujos, dominado por un origen) vs un benigno global; en A4 el confusor de referencia es C2 ([[Controles C1 y C2]]).
