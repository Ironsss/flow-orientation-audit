# Simulador y Generator v2

El simulador original **bloqueó seis mediciones** (techo PR-AUC, sin clase negativa en infiltración, AUC 1.0000
en brute force, confusor de tamaño, saturación en ambos experimentos de restricción). Lección: *el instrumento
es el bloqueante*. Generator v2 pasó Phase 0 para niveles acotados (`P2_*` en `docs/methodology/`), lo que hizo
posible el veredicto de [[H2 topologia bajo restriccion]]. Criterio vinculante: el baseline per-flujo no debe saturar.
