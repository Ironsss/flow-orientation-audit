# Orientación vs separabilidad

Distinción estándar aplicada a una feature fija: el signo ([[AUC_signed]]) puede no transportar mientras la
separabilidad ([[AUC_sep]]) sigue alta. Un cambio de signo no redujo la separación de forma consistente (cayó en
algunos casos, subió en otros). Es el núcleo de [[Tesis vigente]].
