# CICIDS-2018

Dataset de **descubrimiento** de [[H3 signo segun mecanismo]]. Hulk 0.023, HOIC/LOIC-UDP 0.003 (agregado
ponderado de HOIC 0.0005 y LOIC-UDP 1.000); Bot 0.838. Nueve de diez capturas carecen de IP, así que la
asignación de dirección del exportador no se pudo verificar por rol.

- Re-export NetFlow-v2 (A4): HOIC y Hulk REVERSED, SSH EMERGED, 6 PRESERVED, 2 BOTH NEUTRAL; el confusor
  C2 ([[Controles C1 y C2]]) no se excluyó → no se atribuye al exportador.
- Errores de etiquetado conocidos (Engelen 2021, Liu 2022); datos corregidos **no probados**.
- Usado también en [[H2 topologia bajo restriccion]] (real).
